R packages

Reusable tools I've written so other researchers don't have to start from scratch.

R packageOn CRANForest ecology

standrecon

Reconstruct historical forest basal area and stem density from present-day inventory data, using species growth rates and decay-class decomposition. Published on CRAN (2026), tested with testthat. Developed from the research code in Forest_Stand_Reconstruction.

View repo CRAN page 
# install from CRAN
install.packages("standrecon")

library(standrecon)
# reconstruct past stand conditions
