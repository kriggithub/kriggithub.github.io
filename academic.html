Software

Reusable tools I've written so other researchers don't have to start from scratch.

standrecon CRAN · 2026

Reconstruct historical forest basal area and stem density from present-day inventory data, using species growth rates and decay-class decomposition. Tested with testthat, and developed from the research code in Forest_Stand_Reconstruction.

Source on GitHubCRAN page
# install from CRAN
> install.packages("standrecon")
> library(standrecon)
